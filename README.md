# pw-relay (パスワード中継ツール)

Teams 会議中に、相手(スマホのみ)のパスワードを、口頭やチャットの平文を使わずに
自分の Windows PC へ渡すためのツールです。自分も画面上でパスワードを見ません。

| ファイル | 役割 |
| --- | --- |
| `docs/index.html` | 相手がスマホで開く暗号化ページ(GitHub Pages で配信) |
| `pw-relay.ps1` | 自分の PC で動かすスクリプト(Windows PowerShell 5.1) |

## 前提

**1対1の会議で、チャットの内容を第三者に書き換えられない**場面で使うことを前提にしています。
この前提のもとでは、守るべきものは「パスワードがチャット履歴・録画・画面に平文で残らないこと」で、
暗号化だけで足ります。そのため、声での読み合わせなどの確認手順はありません。

前提が崩れる場面(参加者が多い、チャットを書き換えられるおそれがある)で使うときは、
[確認コードを照合する](#確認コードを照合したいとき)を参照してください。

## しくみ

チャットを流れるのは公開鍵と暗号文だけです。秘密鍵はスクリプトのメモリから出ません。

1. PC が、公開中のページが記録どおりの内容かを確かめる(SHA-256 の照合。自動)
2. PC がその場かぎりの RSA 3072bit 鍵ペアをメモリ上に作る
3. 公開鍵を URL の `#` 以降に載せて相手へ送る(`#` 以降はサーバーに送信されない)
4. 相手のスマホがページ内でパスワードを暗号化(RSA-OAEP / SHA-256)し、`PWR1:...` を返す
5. PC が復号し、Win+V 履歴・クラウド同期に残らない形でクリップボードへ入れる
6. 貼り付けたらクリップボードを消去し、鍵を破棄する

## 初回の準備(一度だけ)

1. このフォルダを GitHub のリポジトリに push する
2. リポジトリの **Settings → Pages** で、Source を **Deploy from a branch**、
   Branch を **main** / **/docs** にして保存する
3. `pw-relay.ps1` 冒頭の `$PageUrl` の既定値が、公開された URL と同じであることを確かめる
4. GitHub アカウントの二要素認証を有効にする(ページを書き換えられないようにするため)

`pw-relay.ps1` を編集するときは、**UTF-8 (BOM付き)・CRLF** のまま保存してください。
BOM が無いと PowerShell 5.1 で日本語が文字化けします。

## 使い方(会議のたびに)

1. PowerShell でスクリプトを実行する

   ```bat
   powershell -ExecutionPolicy Bypass -File .\pw-relay.ps1
   ```

2. 「URL をコピーしました」と出たら、Teams のチャットに貼り付けて送る
3. 相手がチャットに返した `PWR1:...` をコピーし、**画面共有を止めてから** PowerShell で Enter を押す
   - メッセージ全体をコピーして構いません。前後の文字や改行は無視されます
   - 暗号文が2つ以上含まれていると受け付けません。最後に届いた1つだけをコピーしてください
4. 「復号しました」と出たら、パスワード欄に Ctrl+V で貼り付ける(チャット欄には貼らない)
5. PowerShell に戻って Enter を押す(クリップボードを消去して終了)
   - Enter を押さなくても **60 秒後に自動で消去**します。足りないときは **E キーで延長**できます
   - 時間を変えるときは `-ClearAfterSeconds 120` のように指定します(`0` で自動消去なし)

途中でやめるときは Ctrl+C を押してください。クリップボードの消去と鍵の破棄は必ず実行されます。
ウィンドウを × で閉じた場合も、見張り役の別プロセス(非表示の PowerShell)が
スクリプトの終了を検知して、復号結果をクリップボードから消去します。

## 相手に送る説明文

```text
これから送るURLをスマホのブラウザー(Safari か Chrome)で開いてください。
パスワードを入力して「暗号化する」を押してください。
出てきた暗号文を「コピー」して、このチャットにそのまま貼り付けて送ってください。
```

## 確認コードを照合したいとき

スクリプトと相手のページには、同じ**確認コード**(4桁×4組)が表示されます。ふだんは見なくて構いません。
URL が途中で書き換えられたかもしれないと思うときだけ、次の2つを**声で**確かめてください。

- 相手のブラウザーのアドレスバーに出ているアドレスが、`$PageUrl` のものと同じ
- 相手のページの確認コードが、PC の表示と全部同じ

どちらかが違えば、パスワードを入力しないよう伝えて中止してください。
確認コードが同じでもアドレスが違えば偽のページなので、必ず両方を確かめます。

## ページを変更したとき

`pw-relay.ps1` は、公開ページの SHA-256 を `$PinnedPageSha256` に記録しています。
`docs/index.html` を書き換えたら、次の値に更新してから push してください。

```bat
powershell -Command "(Get-FileHash docs\index.html -Algorithm SHA256).Hash.ToLower()"
```

- `docs/index.html` の改行は LF に固定しています(`.gitattributes`)。CRLF で保存するとハッシュが変わります
- push してから公開ページに反映されるまで、最大 10 分ほど「一致しません」と出ます
- ネットワークの都合でページを取得できない環境では `-SkipPageCheck` で省略できます(安全性は下がります)

## 知っておくこと

- **貼り付けできない画面があります。** Windows のサインイン画面・ロック画面や UAC の資格情報入力は
  通常のクリップボードが使えない場合があります。本番の前に、実際に使う画面でダミー文字列を試してください。
- **ページのハッシュ照合が確かめるのは、この PC が受け取った内容だけです。** GitHub アカウントを
  乗っ取られると防ぎきれないので、二要素認証を必ず有効にしてください。
- 鍵は 1 回の実行ごとに使い捨てです。スクリプトを終了すると、その URL で作った暗号文は誰にも復号できません。
- 貼り付けるまでの間、復号結果は他のプログラムから読める状態です。Win+V 履歴とクラウド同期からは
  除外していますが、除外指定を無視する常駐ソフトや、リモートデスクトップのクリップボード共有には見えます。
- PowerShell のトランスクリプトやスクリプトブロックログが有効な PC でも、復号結果は記録されないように
  作っています(画面に出さず、コマンドの引数にも渡しません)。
- 暗号化できるパスワードは UTF-8 で最大 318 バイトです。改行などの制御文字を含むものは受け付けません。
- ページは外部との通信を行いません(CSP `default-src 'none'`)。
