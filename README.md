# pw-relay (パスワード中継ツール)

Teams 会議中に、相手(スマホのみ)のパスワードを、口頭やチャットの平文を使わずに
自分の Windows PC へ渡すためのツールです。自分も画面上でパスワードを見ません。

| ファイル | 役割 |
| --- | --- |
| `docs/index.html` | 相手がスマホで開く暗号化ページ(GitHub Pages で配信) |
| `pw-relay.ps1` | 自分の PC で動かすスクリプト(Windows PowerShell 5.1) |

## しくみ

1. PC がその場かぎりの RSA 3072bit 鍵ペアをメモリ上に作る
2. 公開鍵を URL の `#` 以降に載せて相手へ送る(`#` 以降はサーバーに送信されない)
3. 相手のスマホがページ内でパスワードを暗号化(RSA-OAEP / SHA-256)し、`PWR1:...` を返す
4. PC が復号し、Win+V 履歴・クラウド同期に残らない形でクリップボードへ入れる
5. 貼り付けたらクリップボードを消去し、鍵を破棄する

チャットを流れるのは公開鍵と暗号文だけです。秘密鍵はスクリプトのメモリから出ません。

## 初回の準備(一度だけ)

1. このフォルダを GitHub のリポジトリに push する
2. リポジトリの **Settings → Pages** で、Source を **Deploy from a branch**、
   Branch を **main** / **/docs** にして保存する
3. 数分後に表示される URL(例 `https://<アカウント名>.github.io/pw-relay/`)を控える
4. `pw-relay.ps1` 冒頭の `param` にある `$PageUrl` の既定値をその URL に書き換える
   (書き換えない場合は、毎回 `-PageUrl` を付けて実行する)

`pw-relay.ps1` を編集するときは、**UTF-8 (BOM付き)・CRLF** のまま保存してください。
BOM が無いと PowerShell 5.1 で日本語が文字化けします。

## 使い方(会議のたびに)

1. PowerShell でスクリプトを実行する

   ```bat
   powershell -ExecutionPolicy Bypass -File .\pw-relay.ps1
   ```

2. 「URL をコピーしました」と出たら、Teams のチャットに貼り付けて送る
3. 相手にページの **確認コード**(8桁)を読み上げてもらい、PC の表示と一致することを確かめる。
   **一致しなければ Ctrl+C で中止**する(URL が途中で書き換えられている)
4. 相手がチャットに返した `PWR1:...` をコピーし、PowerShell で Enter を押す
   - メッセージ全体をコピーして構いません。前後の文字や改行は無視されます
   - 「見つかりません」「復号できません」と出たら、コピーし直すか、もう一度暗号化してもらう
5. 「復号しました (N 文字)」と出たら、パスワード欄に Ctrl+V で貼り付ける
6. PowerShell に戻って Enter を押す(クリップボードを消去して終了)

途中でやめるときは Ctrl+C を押してください。クリップボードの消去と鍵の破棄は必ず実行されます。
**ウィンドウを × で閉じた場合は後始末が走らない**ので、Ctrl+C か Enter で終わらせてください。

## 相手に送る説明文

```text
これから送るURLをスマホのブラウザーで開き、表示される「確認コード」を読み上げてください。
こちらのコードと同じだと確認できたら、パスワードを入力して「暗号化する」を押してください。
出てきた暗号文を「コピー」して、このチャットにそのまま貼り付けて送ってください。
```

## 知っておくこと

- **貼り付けできない画面があります。** Windows のサインイン画面・ロック画面や UAC の資格情報入力は
  通常のクリップボードが使えない場合があります。本番の前に、実際に使う画面でダミー文字列を試してください。
- 鍵は 1 回の実行ごとに使い捨てです。スクリプトを終了すると、その URL で作った暗号文は誰にも復号できません。
- 確認コードは鍵のすり替え(中間者)対策です。必ず**音声で**照合してください(チャットで照合しても意味がありません)。
- 貼り付けるまでの間、復号結果はクリップボードに平文で入っています。Win+V 履歴とクラウド同期からは
  除外していますが、除外指定を無視する常駐ソフト(一部のクリップボード管理ツール)には見えます。
- 貼り付け先がパスワード欄であることを確かめてから貼り付けてください(チャット欄に貼ると画面共有に映ります)。
- 暗号化できるパスワードは UTF-8 で最大 318 バイトです。
- ページは外部との通信を行いません(CSP `default-src 'none'`)。ページを書き換えられるのは
  リポジトリに書き込める人だけです。
